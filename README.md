# JB Protocol Website

Premium event-protocol website for JB Protocol, Kigali, Rwanda.

## Features
- Premium dark navy / champagne visual identity
- Responsive mobile-first layout
- Animated cinematic hero background
- Services section
- JBP standard / approach section
- Event inquiry form
- WhatsApp pre-filled inquiry
- Phone, email and Instagram links
- No database required
- Static HTML/CSS/JS — easy to deploy on Vercel or GitHub Pages
